# Set and Tic-Tac-Toe

Учебный C++-проект по ООП. Реализует две сущности:

- неориентированное канторовское множество;
- игру «крестики-нолики» на поле произвольного размера.

Логика отделена от консольного интерфейса.

## Возможности

### Set

- вложенные множества;
- добавление, удаление, проверка принадлежности;
- объединение, пересечение, разность;
- проверка на подмножество;
- множество всех подмножеств;
- разбор из строки и вывод в поток;
- сравнение на равенство.

### Tic-Tac-Toe

- поле n × n, настраиваемая длина линии для победы;
- проверка и выполнение хода;
- определение победителя, ничьей, конца игры;
- доступ к клеткам через `operator[]`;
- сравнение, ввод/вывод через потоки;
- сброс игры.
